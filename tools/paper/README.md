# Manuscript

Sources of *YOLO11-DLA: Fallback-Free Object Detection on NVIDIA DLA for Embedded Robotic Perception*, eight pages, IEEE conference format (`ieeeconf`, US Letter, 10 pt, double-anonymous draft).

```bash
make -C tools/paper                    # build main.pdf with Tectonic, then run the preflight
make -C tools/paper check              # preflight only: pages, fonts, links, bookmarks, TeX warnings
make -C tools/paper precision-results  # regenerate tables/*.tex and figures/precision_latency.* from measured CSVs
make -C tools/paper audit              # re-audit the FP16 traces, regenerate analysis/ and the audit figures
make -C tools/paper check-model        # deterministic CPU ONNX and decoder verification
```

`make` needs Tectonic; `check` needs PyMuPDF; `precision-results` and `audit` need NumPy and Matplotlib; `audit` and `check-model` also need PyTorch, and `check-model` additionally ONNX and ONNX Runtime.

## Contents

| Path | Contents |
|---|---|
| `main.tex`, `sections/`, `references.bib` | The manuscript |
| `tables/*.tex` | **Generated** by `make precision-results` from the measured summary CSVs — do not edit by hand |
| `figures/precision_latency.{pdf,svg}` | Generated by the same command |
| `figures/fallback_profile.{pdf,svg}` | Generated by `make audit` from the FP16 layer profiles |
| `figures/teaser.pdf`, `architecture_overview.pdf`, `c2dla_detail.pdf` | Hand-drawn vector schematics |
| `figures/boundary.tex`, `c2dla.tex` | The float and caption wrappers that include the two schematics |
| `analysis/` | Derived CSV/JSON: checkpoint history, engine and layer summaries, FP16 audit, precision results, model verification, PDF preflight |
| `audits/` | Long-form evidence, model, reference and editorial audits, and the manuscript revision record |

`analysis/precision_results.json` records the SHA-256 of each CSV the tables were generated from; those hashes verify against the copies in `logs/`. The mapping from every table cell to its source file is in [`../../docs/RESULTS.md`](../../docs/RESULTS.md).

Nothing in `tools/experiments/` writes values into the manuscript implicitly: `precision-results` regenerates the table files explicitly, and `check_paper.py` only reports.

## Preflight

`check_paper.py` asserts exactly eight US Letter pages, no encryption, empty author metadata, no bookmarks, no embedded links, no Type 3 fonts, every font embedded, and no overfull boxes or unresolved references in `main.log`. It writes `analysis/paper_preflight.json`. It is a local format check and does not replace the submission portal's own checker.
